# dotfiles

My macOS setup: zsh + oh-my-zsh, Neovim (LazyVim), AeroSpace tiling and VS Code.

## What's inside

| Package | What it is |
|---|---|
| `zsh` | `.zshrc` (aliases, `dev` iTerm launcher), `rcb` helper for Claude Code Remote Control, startup banner |
| `git` | `.gitconfig`, global gitignore, `commit-msg` hook enforcing [Conventional Commits](https://www.conventionalcommits.org) |
| `nvim` | [LazyVim](https://www.lazyvim.org) config with custom plugins (auto-save, toggleterm, peek, conform…) |
| `aerospace` | [AeroSpace](https://github.com/nikitabobko/AeroSpace) tiling window manager |
| `vscode` | VS Code `settings.json` and `keybindings.json` |
| `Brewfile` | every Homebrew formula, cask, VS Code extension and global npm package I use |
